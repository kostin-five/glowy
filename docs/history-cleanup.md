# Очистка истории — локальная копия, публикация не выполнена

Очистка текущих файлов не убирает старые документы, реквизиты и commit metadata.
Согласованный rewrite выполнен в отдельной локальной копии: одиннадцать выбранных документов,
исторические личные реквизиты и email владельца в commit/tag metadata.
Авторские сведения другого участника сохранены. Исходный checkout и GitHub не переписаны.
Дополнительный исторический `docs/handoffs/NEXT_CHAT_PROMPT_V2.9.0.md` исключён
после отдельного согласия владельца. Повторный scan не нашёл исключённых путей или
согласованных заменяемых значений. Публикационная проверка ещё не завершена:
незакоммиченные исправления пока не включены в очищенную историю.

## Резервная копия Git

2026-10-06 создан и проверен приватный bundle вне репозитория, содержащий все
текущие refs и их историю. Незакоммиченные изменения и `.env` в него не включены.
Перед локальным rewrite дополнительно проверен свежий bundle и отдельно сохранены
незакоммиченные файлы и diff без env-значений. App-local refs/codex с внутренними
снимками исключены только из публикационной копии; они сохранены в backup.
Местоположение приватной копии и личные значения не публикуются в этом документе.
Перед будущим применением к рабочему checkout потребуется свежий backup.

Из корня проекта после review состояния:

```sh
git bundle create /absolute/private/location/glowy-before-public.bundle --all
git bundle verify /absolute/private/location/glowy-before-public.bundle
git clone --mirror https://github.com/kostin-five/glowy.git /absolute/private/location/glowy-public-cleanup.git
```

Пути здесь placeholders; выбрать новый приватный каталог вне репозитория. Bundle
сохраняет refs/commits, но не некоммиченные файлы или проигнорированные secrets.
Документы отдельно скопированы приватно; credentials не архивировать публично.

## Review плана

В отдельном mirror перечислить refs и историю. Проверить 11 исключённых документов
из `publication-manifest.md` и все исторические legal pages. Для авторских metadata
согласовать замену на GitHub noreply; не анонимизировать сторонних авторов вслепую.

Пример для согласованного удаления внутренних handoff целиком:

```sh
git filter-repo --path docs/handoffs/ --invert-paths
```

Не выполнять в основном checkout. Для остальных путей подготовить полный reviewed список перед
одним запуском. Вместо удаления всей истории legal pages можно заменить конкретные
согласованные значения через приватный файл `--replace-text`; он содержит личные
данные и не должен находиться в Git или переписке.

Авторские email меняются через согласованный приватный mailmap (`--mailmap`). После
rewrite повторить scan всех refs/reflog и проверить, что старые ветки/tags не сохраняют
исходные объекты. Изолированный mirror не меняет локальную рабочую ветку автоматически.

## Публикация

Не выполнять force push автоматически. Владельцу нужно отдельно согласовать push
очищенных refs и действия со старыми clones, forks, PR refs и GitHub artifacts.
GitHub может сохранять старые данные вне обычных branch refs; после удаления секретов
их всё равно требуется отозвать и проверить соответствующие cached views.
