# v2.3.0 — Профиль и персонализация

Glowy получил серверные настройки профиля: пользователь выбирает аватар из
подготовленного набора и один из трёх стилей общения AI — спокойный, умеренный
или жёсткий. Жёсткий тон остаётся уважительным и не меняет права, лимиты,
данные или маршрутизацию AI.

Для первого создания задачи добавлена компактная одноразовая подсказка. Она не
блокирует форму, сохраняет закрытие локально и не дублирует уже существующие
объяснения энергии и Разгрузки мыслей. Landing Page и auth-функции v2.6.0 не
изменялись.
