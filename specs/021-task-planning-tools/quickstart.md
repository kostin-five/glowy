# Quickstart: проверка инструментов планирования

1. Создать задачи с разными датами, энергией, приоритетами и категориями; проверить одиночные/комбинированные фильтры и сброс на desktop/mobile.
2. В новой задаче запросить AI-шаги, изменить один, удалить один, отменить; убедиться, что ничего не сохранено. Повторить и подтвердить, затем сохранить форму.
3. В существующей задаче запросить шаги, подтвердить и проверить отсутствие дублей. Смоделировать provider/limit/partial add failure.
4. Проверить, что Network не содержит mutation до подтверждения и что UI показывает loading/error/retry.
5. Запустить contracts, backend tests, frontend typecheck/lint/unit/build и focused Playwright.
