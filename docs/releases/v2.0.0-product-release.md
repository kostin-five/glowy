# Релиз v2.0.0 - Product Release

## Обзор

Релиз v2.0.0 переводит Glowy от production MVP к более цельному продукту вокруг задач, AI-планирования, энергии и прогресса.

Главный фокус релиза - Tasks 2.0: более устойчивый data contract для дат, улучшенное отображение задач, мобильный UX, множественный выбор, сортировка, группировка и подготовка точек для будущих AI-функций.

## Изменения

### Tasks 2.0

* обновлена страница `/tasks`;
* доработаны вкладки задач:
  * `Активные`;
  * `Выполненные`;
  * `Все`;
* во вкладках добавлены счетчики задач;
* улучшены поиск, сортировка и переключение list/grid;
* исправлено поведение FAB на мобильных и средних экранах;
* добавлен режим множественного выбора задач;
* добавлена bulk-панель действий;
* добавлены массовые действия для выбранных задач;
* улучшены create/edit модалки;
* добавлена placeholder-кнопка AI с сообщением, что функция скоро появится;
* устранены конфликтующие чекбоксы selection/completion;
* улучшена адаптация под узкие экраны.

### Unified date contract

Для задач введен единый frontend-contract:

```text
Task.date = "YYYY-MM-DD" | ""
```

Что сделано:

* добавлена нормализация дат во frontend-слое;
* legacy `DD.MM.YYYY` поддерживается как входной формат;
* пустая дата сохраняется как `""`;
* UI больше не должен рендерить raw `task.date`;
* карточки задач используют форматтер для отображения даты;
* группировка и сортировка используют безопасный local-date parser;
* снижены риски timezone bugs от прямого `new Date("YYYY-MM-DD")`.

### Task grouping и sorting

* добавлена группировка задач по дате;
* заголовки групп показывают понятные подписи:
  * `Сегодня`;
  * `Завтра`;
  * `Вчера`;
  * `5 июля`;
  * `5 июля 2026`;
  * `Без даты`;
* сортировка по названию отображается без date group headers;
* для сортировок по дате, приоритету, энергии и категории используются групповые разделители;
* добавлены прямые и обратные варианты сортировок;
* исправлена логика, при которой сортировка менялась только внутри одного дня.

### Task cards UI

* удалено raw date rendering;
* дата в карточках отображается через единый formatter;
* карточки стали стабильнее в list mode;
* drag overlay использует тот же UI-format для даты;
* сохранены действия:
  * завершение задачи;
  * удаление;
  * редактирование;
  * добавление подзадач;
  * drag-to-trash.

### Analytics 2.0

* обновлен `/analytics`;
* добавлен недельный график выполненных задач;
* добавлено переключение последних недель;
* tooltip графика показывает день и дату;
* исправлен визуальный focus на графике при нажатии;
* улучшена мобильная компоновка аналитики.

### Progress ladder

* обновлен `/stairs`;
* лестница прогресса стала главным визуальным блоком страницы;
* текущий уровень вынесен после лестницы;
* правила начисления XP спрятаны в popup-подсказку;
* добавлен блок `XP за сегодня`;
* улучшена responsive-компоновка карточек;
* увеличены визуальные элементы лестницы на больших экранах.

## Известные ограничения / что дальше

* новые task-поля вроде `description`, `time`, `recurrence`, `source` не добавлялись, потому что требуют отдельного backend/DB-плана;
* production Prisma migrations требуют baseline/repair-плана перед новыми DB changes;
* AI-кнопка в task modal пока является placeholder;
* AI limits еще не полностью связаны с тарифами;
* часть метрик прогресса использует текущие поля задач без отдельной event-history модели.
