# UI Contract: Подтверждаемый план дня

## Recommendation

- Вход: активные задачи, энергия 0–100 и локальная дата `YYYY-MM-DD`.
- Выход: не более 1 задачи при энергии ≤30, 2 при 31–70, 3 при ≥71.
- Порядок: просроченные → сегодня → без даты → будущие; внутри группы соответствие энергии,
  приоритет, подходящая длительность, русский заголовок и id.
- Reason не содержит обещания AI и объясняет ведущий фактор первого кандидата.

## Review dialog

- Заголовок: `План на сегодня`.
- Каждый пункт — доступный checkbox, название задачи, причина и статус `Уже на сегодня` либо
  `Будет перенесена на сегодня`.
- Открытие/toggle/close: 0 task updates.
- Primary action: `Добавить в план`; disabled при пустом выборе или applying.
- Secondary action: `Отмена`; во время applying закрытие заблокировано.

## Apply

- Только выбранные задачи с датой не сегодня получают patch `{ date: today }`.
- Уже сегодняшние не обновляются.
- Full success закрывает dialog и показывает спокойное подтверждение в Focus section.
- Partial failure оставляет failed выбранными и показывает `Не удалось добавить: N` с возможностью повтора.

## Analytics and privacy

Разрешены события `day_plan_opened` и `day_plan_applied` без параметров. Task id/title/category,
даты, энергия и тексты пользователя не передаются. Новых логов нет.
