# v2.6.0 — Offline-режим задач

Glowy сохраняет задачи и подзадачи авторизованного пользователя в локальной
браузерной базе. После хотя бы одного открытия списка задач с интернетом его
можно просматривать, создавать, редактировать, завершать и удалять без сети.
Изменения сразу отражаются в интерфейсе и переживают перезагрузку страницы.

Отложенные действия хранятся в очереди отдельно для каждого аккаунта. Когда
соединение возвращается, Glowy последовательно отправляет их на backend,
заменяет временные локальные идентификаторы серверными и получает свежий список
задач. Статус в интерфейсе показывает отсутствие сети, синхронизацию и действия,
которые требуют повторной попытки. Кэш одного аккаунта не показывается другому.

Offline-режим этого релиза ограничен задачами и подзадачами. AI, глубокая
аналитика, платежи, вход и регистрация требуют интернет; перед вызовом AI или
оформлением тарифа пользователь получает понятное объяснение. Гостевой режим
продолжает использовать прежнее локальное хранение и не синхронизируется с
backend.

Релиз не меняет Prisma-схему и не требует миграции базы данных. Основные
автоматические проверки покрывают очередь операций, восстановление задачи после
offline-перезагрузки, синхронизацию при reconnect и изоляцию аккаунтов.
