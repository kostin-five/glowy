# v2.5.0 — Аналитика и Focus

Аналитика недели и месяца теперь рассчитывается backend по данным текущего
пользователя. Экран показывает выполненные задачи, распределение по энергии,
стрик и сравнение планового с фактическим временем, включая честные пустые и
ошибочные состояния.

Focus и Founder могут вручную запросить глубокий AI-разбор. Недельный разбор
списывает 5 единиц дневного AI-лимита, месячный — 10. AI получает исключительно
агрегаты, не названия задач или сообщения. Успешные авторизованные AI-вызовы
учитываются в дневной unit-экономике по провайдеру, модели, тарифу и токенам без
хранения пользовательского текста.

Миграция для профиля, прогресса и аналитики подготовлена как аддитивная, но не
применяется автоматически. Dev и production требуют отдельного операторского
шага; для Timeweb перед ним обязателен свежий backup.
