# Glowy v2.2.1 — AI Providers & Founder

## Что изменилось

- Backend напрямую обращается к DeepSeek и использует GigaChat как единственный fallback при timeout, сетевой ошибке, HTTP 429 или HTTP 5xx.
- OAuth-токен GigaChat кешируется в памяти и обновляется без передачи ключей на frontend.
- Успешные AI-вызовы пишут безопасные метрики провайдера, модели, задержки и токенов без промпта или ответа пользователя.
- Gemini удалён из активного backend и rollback proxy кода.
- Бесплатный пожизненный тариф переименован в Founder для действующих владельцев; срок и лимит 100 AI-запросов в день сохранены.
- Новая бесплатная выдача Founder закрыта на backend по умолчанию.
- Будущий платный Forever подготовлен в существующем YooKassa flow, но серверный checkout выключен до решения по цене и unit-экономике.
- Изменения не требуют Prisma migration.

## Безопасный rollout

1. Настроить DeepSeek и GigaChat только в backend env dev-среды.
2. Проверить parse, chat и анализ задач через DeepSeek.
3. Смоделировать временную ошибку DeepSeek и проверить один ответ GigaChat.
4. Повторить smoke-test на Timeweb.
5. Только после этого удалить отдельный proxy process и его секреты.
6. Оставить `FOUNDER_SIGNUP_ENABLED=false` и `PAID_FOREVER_ENABLED=false`.

## Отложено

- Серверная история диалогов.
- Настраиваемые стили общения Glowy.
- Публикация цены и включение платного Forever.
