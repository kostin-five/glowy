# UI Contract: Глобальное быстрое создание задачи

## Open action

- Каждая точка входа вызывает общий launcher без task payload.
- Повторный вызов не создаёт второй dialog.
- В момент открытия маршрут не меняется.

## Presentation

- Используется существующий dialog с заголовком «Создать задачу».
- Desktop Sidebar показывает «Новая задача»; в collapsed-состоянии остаются icon, `aria-label` и tooltip.
- Mobile Header и Glowy AI page header показывают кнопку не менее 44×44 px с `aria-label="Новая задача"`.
- Текущие логотипы и центральная сфера не меняются.

## Focus and close

- При открытии фокус получает название задачи.
- Escape, backdrop, X и «Отмена» закрывают dialog по существующим правилам.
- После закрытия фокус возвращается к вызвавшей кнопке, если она остаётся в DOM.

## Mutation boundary

- Open/close сами не создают и не меняют данные.
- Создание происходит только через существующую кнопку «Сохранить задачу».
- Error, retry, duplicate-submit и offline semantics остаются контрактом `CreateTaskModal` и task store.

## Rollback

- Удалить global entry points и вернуть локальное владение modal на TaskPage.
- Пользовательские задачи и настройки формы не требуют преобразования или восстановления.
