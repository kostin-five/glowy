# Релиз v1.5.4 - AI Reliability Patch

## Обзор
Этот релиз направлен на повышение стабильности и отказоустойчивости AI-интеграции в приложении Glowy. Основное внимание уделено обработке ошибок Gemini, внедрению механизмов повторных попыток (retry) и улучшению пользовательского опыта при временной недоступности ИИ.

## Изменения

### AI Proxy
- **Улучшенный Retry**: Добавлен механизм повторных попыток для более широкого спектра ошибок, включая общие сбои запросов.
- **Fallback Model**: Реализована поддержка переключения на резервную модель (`GEMINI_FALLBACK_MODEL`), если основная модель недоступна или перегружена.
- **Privacy-safe Logging**: Из логов удалены полные тексты пользовательских сообщений. Теперь логируются только метаданные: тип операции, используемая модель, длительность и безопасные коды ошибок.

### Backend
- **Мягкие ошибки**: Технические коды ошибок (например, `GEMINI_UNSUPPORTED_LOCATION`) заменены на понятные пользователю сообщения на русском языке.
- **AI Error Contract**: Введен единый формат ответа при ошибках ИИ, включающий флаг `retryable`, который подсказывает фронтенду, имеет ли смысл предлагать повторную отправку.
- **Graceful Fallback**: При сбое парсинга задач в Хабе мыслей теперь используется упрощенный алгоритм выделения задач из текста, что позволяет не ломать пользовательский сценарий.

### Frontend
- **Улучшенный UX ошибок**: Backend теперь возвращает дружелюбные сообщения вместо технических формулировок. Текущий UI отображает эти тексты, а добавленный в контракт флаг `retryable` позволяет в будущем более точно управлять кнопками повторной отправки.

## Проверка
- [x] Обработка перегрузки ИИ (retry на уровне прокси).
- [x] Переключение на fallback модель при сбоях.
- [x] Отсутствие персональных данных в логах AI Proxy.
- [x] Понятные сообщения об ошибках в Хабе мыслей.
- [x] Сохранение работоспособности сценария «Мысль -> Задача» при сбоях ИИ.

## Примечания
- Интеграция YandexGPT и других провайдеров не входит в данный патч и запланирована на будущие версии.
