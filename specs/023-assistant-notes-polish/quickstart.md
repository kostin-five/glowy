# Quickstart Validation

1. Run `npm run dev` and open the app on desktop.
2. Choose each preset wallpaper and a custom wallpaper; open `/ai` and verify the background remains visible behind readable surfaces.
3. Verify desktop navigation and Settings → Interface call the section «Ассистент».
4. At 320–430 px, open the center assistant control and the full `/ai` page; verify controls are reachable.
5. Open `/notes`, search, select a note, edit title/content, save, return, archive and restore it.
6. Link/unlink a task and request a task draft from selected text; cancel once, then explicitly confirm once.
7. Run focused tests and `npm run typecheck`.
