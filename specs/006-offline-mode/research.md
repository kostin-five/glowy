# Research

- **IndexedDB вместо localStorage**: асинхронное хранилище подходит для снимков и очереди; нативный API избегает новой зависимости.
- **Local-first внутри текущего Zustand store**: UI обновляется сразу, а существующие API вызываются replay-процессором.
- **Отрицательные временные ID**: сохраняют текущий числовой контракт и однозначно отличаются от серверных ID.
- **Последовательный replay + Web Locks**: сохраняет порядок зависимых операций и предотвращает двойную отправку из вкладок.
- **Сессия при сетевой ошибке**: сохранённая сессия остаётся только для чтения локальных данных; `401/403` очищают её.
- **Без Prisma migration**: весь новый формат относится к браузеру, серверная схема не меняется.
