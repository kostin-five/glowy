# Релиз v1.5.3 - Auth & Storage Cleanup

## Обзор
Этот релиз направлен на очистку и укрепление слоя авторизации и хранения данных перед коммерческим запуском v2.0.0. Основное внимание уделено исправлению предупреждений rate-limit, добавлению эндпоинта профиля и гигиене локального хранилища.

## Изменения

### Backend
- **Rate-limit IP Key**: Исправлено использование `req.ip` в `keyGenerator` для устранения предупреждения `ERR_ERL_KEY_GEN_IPV6`. Теперь используется стандартный механизм определения IP.
- **Auth Profile**: Добавлен эндпоинт `/api/auth/me`, возвращающий безопасный профиль текущего пользователя (id, name, email, xp, level, createdAt).
- **Password Policy**: Минимальная длина пароля при регистрации увеличена до 8 символов для повышения безопасности.
- **Auth Middleware**: Подтверждена поддержка HttpOnly cookie как основного метода авторизации.

### Frontend
- **Storage Hygiene**: Улучшена очистка данных при выходе из системы. Теперь при `logout` полностью очищаются:
  - Состояние авторизации (`auth-storage`).
  - Кэш задач (`glowy-tasks`).
  - Прогресс пользователя.
  - Устаревшие (legacy) токены из localStorage.
- **Demo/Offline Separation**: Усилено разделение между демо-режимом и авторизованной сессией. При выходе демо-данные не сохраняются для следующего пользователя.

## Проверка
- [x] Регистрация с паролем >= 8 символов.
- [x] Вход и получение профиля через `/api/auth/me`.
- [x] Выход с полной очисткой localStorage.
- [x] Отсутствие предупреждений `ERR_ERL_KEY_GEN_IPV6` в логах.
- [x] Сохранение работоспособности HttpOnly cookie.
