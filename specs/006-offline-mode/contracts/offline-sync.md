# Offline Sync Contract

Offline replay использует только существующие `TaskApi` и `SubTaskApi`.

1. Снимок загружается до сетевого обновления.
2. Локальная команда сначала сохраняется в IndexedDB, затем может быть отправлена.
3. Операции отправляются по одной в порядке `createdAt`.
4. Успех удаляет операцию; создание также заменяет временный ID.
5. Network error, timeout, 429 и 5xx оставляют команду для повтора.
6. Остальные 4xx останавливают replay и требуют внимания пользователя.
7. После пустой очереди выполняется GET задач и сохраняется свежий снимок.
8. API и Prisma schema не расширяются в v2.6.0.
