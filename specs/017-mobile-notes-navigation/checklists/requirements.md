# Specification Quality Checklist: Мобильная навигация заметок

- [x] Scope ограничен frontend-навигацией и компоновкой заметок.
- [x] Все требования проверяемы и не зависят от реализации новой архитектуры.
- [x] Безопасность несохранённых изменений и ошибка API описаны явно.
- [x] Desktop, deep-link, browser back, архив и целевые mobile-ширины учтены.
- [x] Backend, БД, auth, AI, Telegram, платежи, landing и production исключены.
- [x] Rollback не требует преобразования или удаления пользовательских данных.
