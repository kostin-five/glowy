# Quickstart Verification

1. Запустить frontend и backend, войти и создать задачу с подзадачей.
2. В DevTools включить Offline и изменить задачу, подзадачу и статус выполнения.
3. Перезагрузить страницу: изменения и статус «Сохранено на устройстве» должны сохраниться.
4. Вернуть Online: дождаться синхронизации и обновить страницу.
5. Выйти, войти другим аккаунтом и проверить отсутствие данных первого аккаунта.
6. Офлайн открыть AI и оплату: запрос не начинается, пользователь получает объяснение.

```bash
npm run typecheck
npm run lint
npm run test
npm run build
cd backend && npm run test
npx playwright test
```
