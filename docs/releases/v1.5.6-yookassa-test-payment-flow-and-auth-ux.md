# Релиз v1.5.6 - YooKassa Test Payment Foundation

## Обзор
v1.5.6 — это релиз, закладывающий фундамент для будущих платежей. Он включает в себя инфраструктуру для работы с ЮKassa, улучшение UX авторизации и подготовку UI для управления тарифами.

**Важно:** v1.5.6 НЕ включает live payments. Боевая оплата перенесена на v1.6.0.

## Изменения

### Frontend
- Реализован `PaymentApi.createFocusPayment()`.
- Реализован `PaymentApi.getCurrentPlan()`.
- Добавлены страницы `/payment/success` и `/payment/cancel`.
- Обновлена страница `/pricing`: добавлен UI для отображения текущего тарифа, даты окончания Focus и disabled-состояние для Focus CTA при неактивном feature flag.
- Авторизованный пользователь может увидеть свой текущий тариф на `/pricing`.
- Активный Focus отображается как текущий тариф, показывает дату окончания и блокирует повторное нажатие CTA на frontend.
- Guest/demo/non-auth пользователи не вызывают методы получения текущего тарифа.
- Страницы успеха/отмены платежа корректно обрабатывают состояния (active/pending/error).

### Feature Flag
- Введен `VITE_PAYMENTS_ENABLED=false` (по умолчанию).
- При `false` checkout полностью недоступен.
- При `true` (для dev) сохраняется тестовый payment-flow.
- Production checkout в v1.5.6 не включен.

### Backend
- Добавлен `GET /api/payments/current-plan`.
- Добавлен `POST /api/payments/focus/create`.
- Добавлен `POST /api/payments/yookassa/webhook` (публичный endpoint).
- Реализована защита от дублирования платежей (duplicate Focus guard): active Focus не создает новый платеж.
- Реализован webhook hardening: проверки ID, статуса, суммы, валюты, метаданных, local payment data и идемпотентность повторных `payment.succeeded`.
- Некорректные webhook-данные не активируют Focus и не помечают платеж как оплаченный.
- `payment.canceled` после уже оплаченного платежа не сбрасывает Focus.
- Prisma Payment model и поля пользователя (`plan`, `subscriptionStatus`, `planExpiresAt`) используются для управления доступом.

### Legal/Commercial
- Подготовлены все необходимые страницы (включая `/requisites`, `/offer`, `/refund-policy` и др.).

## Deferred to v1.6.0 (Not included in v1.5.6)
- Production YOOKASSA_* env setup.
- Production webhook setup in YooKassa cabinet.
- VITE_PAYMENTS_ENABLED=true в production.
- Live checkout.
- Real production payment test.
- Receipts/самозанятость/Мой налог operational checklist.
- Live pricing copy polish.
- Special frontend handling for FOCUS_ALREADY_ACTIVE.
- Cancel redirect verification.
