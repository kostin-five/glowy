# Documentation contract

Every active onboarding source must answer:

- what is verified in production;
- what exists only in local development;
- which document is canonical for each layer;
- how frontend, TypeScript backend, Prisma and AI are currently structured;
- what commands are read-only and what actions require owner approval;
- which checks are expected for a future change;
- that the next agent waits for a concrete task before editing.
