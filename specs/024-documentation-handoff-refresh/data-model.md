# Documentation state model

No runtime data model changes.

Documentation distinguishes:

1. **Historical snapshot** — true only at the date of an archived handoff/release note.
2. **Verified production** — last state manually confirmed by the owner on Timeweb.
3. **Local development** — current Git/worktree state, possibly unpushed and never assumed deployed.
4. **Planned direction** — roadmap intent, not a release promise or implementation fact.
